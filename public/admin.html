如何申請 TDX API

  1. 前往 tdx.transportdata.tw 註冊帳號
  2. 登入後至「應用程式管理」建立新應用程式
  3. 取得 Client ID 與 Client Secret
  4. 到 Vercel → Settings → Environment Variables 填入
  5. Redeploy 後生效
